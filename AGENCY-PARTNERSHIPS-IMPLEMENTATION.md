## Lead capture and measurement

The dedicated form asks for contact name, business email, company and a short brief. Website, capability, project stage, timing, collaboration model, indicative budget and contact preference are optional. The notification still uses email for the first reply. The shared contact page preselects Agency through `/contact/?service=agency&source=agency` and lets visitors choose an ordinary business enquiry instead.

The endpoint at `/api/enquiry/` reuses server validation, exact-origin and request size checks, Turnstile, rate limits, the honeypot, short-lived Redis receipts and Resend idempotency. It derives `audience=agency` from the validated service, checks capability keys, and sends the brief as plain text. The owner inbox is the destination for actual submissions. The preview offers the existing WhatsApp contact with a draft in the meantime. Scheduling remains deferred.

| Event                  | Measurement                                                                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `page_view`            | Existing GA4 page view, using an allowlisted agency campaign location.                                                                                                                     |
| `click_agency_cta`     | Approved placement and destination, including hero, proof, enquiry, footer and the relevant entry links.                                                                                   |
| `start_agency_enquiry` | First real agency-form interaction.                                                                                                                                                        |
| `form_error`           | Existing event with a fixed reason and categorical context.                                                                                                                                |
| `generate_lead`        | Fresh accepted response with the matching receipt. Adds `lead_type=agency`, safe `service_interest` and page path. Validation errors, provider failures and replays have zero conversions. |
| `click_whatsapp`       | Agency WhatsApp outbound action.                                                                                                                                                           |

GA4 uses the existing analytics preference. Form events carry categorical values only. The agency page preserves approved `utm_source`, `utm_medium` and `utm_campaign` values for acquisition. Other query values are omitted from agency measurement, and campaigns stay out of the lead payload. The collector test verifies the intended page location without recording the hit in the live property. The agency URL occurs once in the generated sitemap and is reachable from service and work pages. There are no competing agency slugs.
